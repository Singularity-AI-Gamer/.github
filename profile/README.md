## 一起共创

1. 从 [agent-skills](https://github.com/Singularity-AI-Gamer/agent-skills) 浏览现有内容，找到可直接复用的工作流。
2. 以可说明、可验证、可脱敏的方式整理你的方法或项目。
3. 通过所在项目的 Issue 或 Pull Request 发起讨论和协作。

## 社区约定

- 公开内容不包含真实凭据、个人隐私、内部资料或客户数据。
- 项目以可复用与可验证为优先，不把未经验证的结论包装成事实。
- 这里是训练营共创空间；仓库内容不代表任何医疗、业务或官方立场。
